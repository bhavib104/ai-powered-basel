# Regulatory Sources

> **Status:** Placeholder — completed in **Phase 6** during document ingestion.

This document will record the provenance of every regulatory document ingested,
so that all citations are traceable and legally obtained. Planned columns:

- Title and document identifier
- Issuing authority (e.g. Basel Committee on Banking Supervision, RBI)
- Publication date (where available)
- Document version
- Source URL
- File checksum (SHA-256)
- License / usage note confirming public availability

No confidential or non-public documents will be used. Earlier document versions
are preserved and never silently overwritten.
